# CampusConnect - University Student Societies Platform

CampusConnect is a modern, responsive React web application designed for university students to discover campus societies, explore upcoming events, view announcements, and connect with their campus community.

## ✨ Features

- **Discover / Home Screen**:
  - Interactive hero section with platform engagement metrics.
  - Featured societies showcase (Technology, Sports, Debating, Arts & Culture).
  - Upcoming events list with RSVP modal and event details.
  - Recent official announcements and notices bulletin.
- **Explore Societies Screen**:
  - Real-time client-side search across society names and descriptions.
  - Category filter chips (*All Societies, Technology, Sports, Arts & Culture, Debating, Social Impact*).
  - Responsive cards with active member counters and verified society badges.
- **Society Details Profile**:
  - Dedicated profile showcasing the Tech & Innovation Society.
  - Interactive **Join Society** toggle and member counter.
  - Executive committee team profiles.
  - Photo gallery showcasing recent campus hackathons and workshops.
- **Modern UI & Design System**:
  - Built with pure CSS3 and Lucide React icons.
  - Premium startup aesthetic with responsive layouts for mobile and desktop.

## 🛠️ Tech Stack

- **React.js** (v19)
- **Vite**
- **React Router DOM** (v7)
- **Lucide React** (Icons)
- **Pure CSS3**

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MuneebAhmad03/Student-Society-Connect.git
   cd Student-Society-Connect
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:5173`.
